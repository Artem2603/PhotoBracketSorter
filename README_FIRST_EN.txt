Photo Bracket Sorter 1.2.1

1. Extract the ZIP to a new empty folder.
2. Run PhotoBracketSorter.exe.
3. ExifTool is bundled; no separate download is needed.
4. Copy keeps originals.
5. Move deletes sources only after copy and size/SHA-256 verification.
6. If you see "Copied, but not deleted", check the copy and permissions before deleting anything manually.

Real HEIC/DNG behavior depends on camera files. This build's automated checks use synthetic files and metadata.
