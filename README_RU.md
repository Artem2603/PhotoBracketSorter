# Photo Bracket Sorter 1.2.1

Portable-приложение Windows для сортировки папок с HEIC/JPEG, RAW/DNG и сериями брекетинга на 3 или 5 кадров.

## Главное

- ExifTool встроен в сборку и находится автоматически после распаковки ZIP.
- RAW + HEIC/JPEG сопоставляются по времени, имени и метаданным.
- `BRACKETING_3` и `BRACKETING_5` определяются независимо.
- Смешанные timezone-aware/timezone-naive времена не приводят к падению.
- Copy не меняет оригиналы.
- Move сначала копирует, проверяет размер и SHA-256, затем удаляет исходник.
- При ошибке удаления показывается статус `Скопировано, но не удалено`.
- Интерфейс поддерживает русский и English, темы, настройки, preview и ручную проверку.

## Где логи

Логи пишутся в `%LOCALAPPDATA%\PhotoBracketSorter\logs`.

## Ограничения проверки

Автотесты используют синтетические файлы и синтетические метаданные. HEIC/DNG/RAW ветки проверены как логика обработки, но в этом прогоне не использовались реальные фотографии пользователя.
