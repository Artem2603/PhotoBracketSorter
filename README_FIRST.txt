Photo Bracket Sorter 1.1.0

Unzip the whole folder and run PhotoBracketSorter.exe.

ExifTool is bundled in _internal/vendor/exiftool. Do not remove exiftool.exe or exiftool_files.

Copy keeps source photos unchanged.
Move copies and verifies files first, then deletes sources only after successful verification.

Use README_FIRST_RU.txt or README_FIRST_EN.txt for the localized quick start.
