# Contributing

Проект ориентирован на безопасность пользовательских фотографий.

Перед изменениями проверьте:

- исходники не удаляются, не перемещаются и не переименовываются;
- нет фоновой сети и телеметрии;
- новые решения записывают reasons и warnings;
- сомнительные случаи уходят в REVIEW;
- тесты покрывают новые правила.

Локальные проверки:

```bat
python -m unittest discover -s tests
```
