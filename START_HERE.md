# Start Here

1. Extract `PhotoBracketSorter-1.2.1-portable.zip` to an empty folder.
2. Run `PhotoBracketSorter.exe`.
3. Choose a source folder copied from your camera or phone.
4. Choose an output parent folder outside the source folder.
5. Click Analyze.
6. Review warnings, preview and categories.
7. Use Copy to keep originals, or Move only after confirming you understand source deletion.

ExifTool is included. You do not need to download it separately.
